## Производитель оборудования и проверенные ноутбуки

**Датчик отпечатков производит компания Goodix (Шэньчжэнь Хуидин Технолоджи); Huawei — производитель самого ноутбука.** Этот репозиторий рассчитан на датчик Goodix `GDIX51C0`: устройство обнаруживается через ACPI, общается по шине SPI и использует линии прерывания и сброса GPIO. На проверенном устройстве датчик сообщает ID чипа `0x2504`, конфигурация ChicagoHS, матрица 80 × 64 пикселя. Windows-драйвер Huawei `gfspi.inf` тоже соответствует `ACPI\GDIX51C0`; его DLL, прошивка и установщик в этот репозиторий **не** входят.

| Ноутбук | Что проверено |
| --- | --- |
| Huawei MateBook D16 2022, RLEF-XX | Этот репозиторий: установка, привязка драйвера spidev, регистрация пальца и `fprintd-verify` работают |
| Huawei MateBook D15 2022, BoF-XX / M1010 | Ветка d15-bofxx: регистрация правого указательного пальца завершена, `fprintd-verify` вернул `verify-match`; вход через GDM после перезагрузки не проверялся |
| Huawei MateBook 16s | Проверен [исходным проектом](https://github.com/berkekbgz/libfprint-goodix-spi); в этой ветке заново не проверялся |

## Что исправлено

Драйвер исходного проекта держит шину SPI «тихой» около 80 мс, пока датчик снимает изображение. На BoF-XX линия прерывания поднимается именно в этот период: поток-слушатель расходует фронт сигнала, пока чтение подавлено, и потом ждёт нового фронта — из-за этого ожидание ответа с изображением `0x17` истекает по таймауту. Ветка d15-bofxx будит поток-слушатель и повторно проверяет уровень прерывания, когда «тишина» заканчивается, а также входит в тихий период прямо в том потоке, который принял ACK съёмки. Подробные журналы, список изменённых файлов и способ отката — в [D15-README.md](D15-README.md).

В этой копии исправление udev-правила из d15-bofxx (шаблон `acpi:GDIX51C0:*`) влито в основную ветку, а `install.sh` доработан: проверка после сборки принимает правило как со звёздочкой, так и без неё — раньше каждая чистая установка прерывалась ошибкой «generated udev rules do not contain supported ACPI id GDIX51C0». Проверено на Huawei MateBook D16 2022 (RLEF-XX): установка, привязка spidev, регистрация пальца и `fprintd-verify` работают.

## Установка и использование

Это производный проект от [libfprint-goodix-spi](https://github.com/berkekbgz/libfprint-goodix-spi). Установочный скрипт скачивает зафиксированную версию libfprint, собирает «теневую» библиотеку и настраивает `fprintd`. По умолчанию также устанавливается пропатченный fprintd с сохранением «обучения» сопоставителя; чтобы оставить fprintd из дистрибутива, используйте `--without-fprintd`.

```bash
./install.sh --without-fprintd
fprintd-enroll -f right-index-finger
fprintd-verify
```

При первом использовании датчику нужен ключ TLS PSK. Стандартная установка может создать и записать новый ключ; на компьютере с двумя системами Windows и Linux могут затирать ключ друг друга. Сначала прочитайте [заметки о первом запуске](https://github.com/berkekbgz/libfprint-goodix-spi#first-run) в исходном проекте. Изображения отпечатков и шаблоны обрабатываются и хранятся на самом компьютере. Разблокировка по отпечатку — удобная функция, и она не должна быть единственным способом подтверждения личности.
