# Исправление съёмки изображения на Huawei MateBook D15 2022 / BoF-XX

[English](D15-README_EN.md) · [中文](D15-README_ZH.md) · [Главная страница проекта](README.md)

[Статья с полным разбором проблемы и её исправления (на китайском)](https://xingwangzhe.fun/posts/matebook-d15-goodix-gdix51c0-fingerprint/)

Ветка d15-bofxx основана на коммите `010a665f54089a1632b1ab7be588b316ace934e2` проекта [berkekbgz/libfprint-goodix-spi](https://github.com/berkekbgz/libfprint-goodix-spi). Датчик отпечатков производит **Goodix (Хуидин Технолоджи)**, ноутбук — Huawei; устройство отпечатков — это `ACPI\GDIX51C0` на шине SPI. Изменены три файла в `drivers/gdix51c0/`; посмотреть сам патч можно командой `git log -p -- drivers/gdix51c0/`.

На этом BoF-XX после ACK режима съёмки датчик поднимает линию прерывания примерно на 80 мс — на время «тихого» периода SPI. Поток-слушатель расходует этот фронт сигнала, но не проверяет повторно линию IRQ, которая остаётся высокой, поэтому ожидание данных изображения `0x17` истекает по таймауту. Исправление будит поток-слушатель по окончании «тишины» и входит в тихий период в том же потоке, который читает ACK.

**Результат на этом ноутбуке 2026-10-11:** регистрация правого указательного пальца завершена, один запуск `fprintd-verify` вернул `verify-match`. После удаления временной диагностической печати служба по-прежнему видела зарегистрированный палец; повторная проверка завершилась таймаутом, потому что датчик не касались. Перезагрузка и вход через GDM не проверялись.

Установленная библиотека находится в `/opt/goodix-spi-driver/libfprint/libfprint-2.so.2.0.0`; версия до изменения сохранена рядом, с суффиксом `.pre-ack-quiet`. Настройка systemd лежит в `/etc/systemd/system/fprintd.service.d/20-goodix-spi-libfprint.conf`, правило привязки SPI — в `/etc/udev/rules.d/70-libfprint-2.rules`. Чтобы откатить только это изменение съёмки, восстановите резервную копию библиотеки с правами администратора и перезапустите `fprintd`; старая версия видела устройство, но не могла завершить регистрацию пальца на этом ноутбуке.
